# Bank_DataAnalysis
A complete Data Analysis project built using Python to explore customer banking behavior, financial patterns, and campaign responses. The analysis is performed using Pandas, NumPy, Matplotlib, and Seaborn.


Dataset Information

The dataset contains banking customer information including:

Age
Salary
Balance
Marital Status
Loan Details
Housing Loan
Contact Type
Campaign Information
Previous Campaign Outcome
Customer Response
Education
Job Type

Total Records: 45,161

Total Columns: 19

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
